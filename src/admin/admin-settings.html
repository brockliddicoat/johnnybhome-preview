Website Address

The address customers type to reach the website. The admin keeps working on any address, so a mistake here can always be fixed.

Does johnnybhome.com Reach This Website?

Check Now
Point johnnybhome.com Here From GoDaddy
  1. Sign in at godaddy.com and open My Products.
  2. Next to johnnybhome.com, choose DNS.
  3. Find the record with type A and name @. Choose Edit and change the value to this server's IP address (your web host lists it in its control panel, often as "Shared IP" or "Server IP"). Save. If there is more than one A record named @, delete the extra ones (any starting with 23.227.38 belong to Shopify).
  4. Find the record with type CNAME and name www. Change the value to johnnybhome.com and save.
  5. Leave the MX and TXT records alone. They deliver the email for service@johnnybhome.com and keep Google Search Console working.
  6. It usually takes under an hour (at most 48 hours). Then tap Check Now above.
  7. Once the check is green, sign in to Shopify, go to Settings › Domains and remove johnnybhome.com. Keep the Shopify plan until you're happy with the new site.

If this website is hosted at GoDaddy too, skip steps 3 and 4: in GoDaddy's hosting dashboard, set johnnybhome.com as the website's domain and GoDaddy updates the records for you.

Request Forwarding

Every request is saved here in the admin and forwarded by email the moment it arrives. To send one kind to several people, separate the addresses with commas.

Email Delivery

Requests are always saved here first. This decides how the email about them is sent.

How to Send Email

Gmail: smtp.gmail.com, port 587, TLS, your Gmail address and an app password (Google Account › Security › App passwords). Outlook or Microsoft 365: smtp.office365.com, port 587, TLS. Your web host's email: usually mail.johnnybhome.com, port 465 with SSL.

Saved your changes? Send a test to service@johnnybhome.com.
